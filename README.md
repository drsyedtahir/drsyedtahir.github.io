# Dr. Syed Tahir Hussain Rizvi, academic portfolio

Vite + React + TypeScript + Tailwind.

- Content: edit `src/data.ts` (add his email in `profile.email`).
- Intro video: drop `avatar-intro.mp4` into `public/video/`. A plain MP4 works. If it has a pure green (#00FF00) background it is made transparent in the browser.
- Run: `npm install && npm run dev`. Build: `npm run build`.
- Deploy: push to a NEW GitHub repo named `<his-username>.github.io` on branch `main`. The workflow in `.github/workflows` deploys it.
